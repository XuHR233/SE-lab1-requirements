# R-601 评价窗口与申诉（REQ-020）

| 行为实例 | 预期 |
|---|---|
| 已完成订单双方提交 1–5 星；同一方重提 | 各一条，后一次更新原记录 |
| 第 14 天最后一秒 / 第 15 天零点 | 前者可操作；后者结束，缺评自动补 5 星且不重复 |
| 删除评价、申诉成立、超时未处理 | 删除与屏蔽不擦除原记录；申诉超时提醒管理员，不自动改判 |
| 非当事人、非管理员 | 分别不能写评价或裁决，拒绝留痕 |

契约：`reviews.services`、`/api/orders/{id}/review/`、评价与申诉入口、`sweep_expired`。
涉及：`reviews/`、`config/`、`trade/management/commands/sweep_expired.py`、`tests/test_m6.py`。
口径：上海时区，第 14 个自然日结束；工作日按周一至周五，提醒通过管理员待办入口展示。
