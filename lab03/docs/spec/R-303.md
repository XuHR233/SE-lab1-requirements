# R-303 尾款与预售订单交接（REQ-006 后半）

## 行为实例

| # | 场景 | 预期 |
|---|---|---|
| 1 | 付清尾款 | 预约「已完成」，生成**待发货**订单，商品「待付款锁定」→「交易中」 |
| 2 | 同一预约付两次尾款 | 返回同一个订单（`Order.source_reservation` 是 OneToOne），不重复建单 |
| 3 | 尾款金额与应付不一致 | 400「支付金额与应付金额不一致」 |
| 4 | 有有效预约时卖家改内容 / 改图 / 下架 | 全部 409 且写 denied 日志（状态图二「待付款锁定期间卖家不得改价改内容」的口径延伸到预约期） |
| 5 | 违规下架带有效预约的商品 | 预约被关闭为「已取消」，定金按全额退，写退款单 |
| 6 | 预约完成后该商品重新出现在列表 | 此时商品已是「交易中」，仍对他人隐藏；订单双方可从订单进详情 |

## 契约

- `reservations/services.py::pay_final(reservation, *, actor, txn_no, now=None) -> Reservation`
  - 逾期先 `_close(...)` 再抛「尾款支付已逾期，预约已关闭」
  - 成功后调 `trade.services.create_presale_order(reservation)`：
    - `amount = deposit + final_amount`，`status = 待发货`
    - 幂等：`Order.objects.filter(source_reservation=reservation).first()` 命中即返回
- `reservations/services.py::cancel_for_takedown(product, *, reason, now=None) -> int`
- `catalog/services.py::revise_content` / `add_image` / `unpublish` 三条守卫：
  `product.is_presale and has_active(product)` → `_deny_transit(..., "该预售商品有有效预约…")`
- `catalog/services.py::takedown` 在 `transit(VIOLATED)` 成功后调用 `cancel_for_takedown`
