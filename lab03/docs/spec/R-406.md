# R-406 手续费与结算（REQ-017）

## 行为实例

| 成交额 | 手续费 | 通道费 0.6% | 平台服务费 0.9% | 卖家实收 |
|---|---|---|---|---|
| 1000.00 | 15.00 | 6.00 | 9.00 | 985.00 |
| 20000.00 | **200.00**（封顶） | 120.00 | 80.00 | 19800.00 |
| 13333.00 | 200.00 | **80.00** | 120.00 | 13133.00 |
| 99.99 | 1.50 | 0.60 | 0.90 | 98.49 |

- 13333 × 0.006 = 79.998 → `ROUND_HALF_UP` 两位小数得 **80.00**（不是 79.99）
- 封顶后平台服务费 = 手续费 − 通道费，通道费按实际成交额计，可以为 0 但不会为负
- 未发货全额退款：不扣平台服务费；已产生的 0.6% 通道费由平台承担（本期不在退款单上体现扣减）

## 契约

- `trade/fees.py::fee_breakdown(amount: Decimal) -> dict[str, Decimal]`
  - 键：`gross` / `fee` / `channel_fee` / `platform_fee` / `seller_net`
  - `RATE = 0.015`、`CHANNEL_RATE = 0.006`、`CAP = 200.00`、`CENT = 0.01`、`ROUND_HALF_UP`
  - `channel = min(round_half_up(gross × 0.006), fee)`，`platform = fee − channel`
- 手续费在**放款时**从卖家应收扣（下单与支付都不扣），落点是 `Settlement` 的三个分项字段
- `Settlement` 唯一约束保证同一订单只结算一次，重复结算不重复放款
