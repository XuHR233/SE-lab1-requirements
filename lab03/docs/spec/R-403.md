# R-403 发货、收货与超时退款（REQ-015）

## 行为实例

| # | 场景 | 预期 |
|---|---|---|
| 1 | 卖家确认发货并填运单号 | 订单「待收货」，记 `tracking_no` 与 `shipped_at` |
| 2 | 买家替卖家发货 | 403 且写 denied 日志 |
| 3 | 运单号 `"123"`（太短）/ 含符号 | 400「运单号不合法」 |
| 4 | 同一运单号重复确认发货 | 返回原订单，只生效一次（REQ-015） |
| 5 | 48 小时内卖家未发货 | 买家可申请全额退款（走 R-405） |
| 6 | 超过 15 天未发货 | `sweep()` 自动全额退款，商品回「已发布」 |
| 7 | 发货前买家申请退款 | 无需卖家同意（REQ-015） |

## 契约

- `trade/services.py::ship(order, *, actor, tracking_no, now=None) -> Order`
  - 运单号校验 `len >= 6 and isalnum()`
  - 幂等：状态已是「待收货」且运单号相同 → 直接返回
- `trade/services.py::sweep(*, now=None) -> int`
  - 「待发货」且 `paid_at + 15 天 <= now` → `_auto_refund(order, now)`
  - 「待收货」且 `auto_confirm_at <= now` → 自动确认收货（R-405）
