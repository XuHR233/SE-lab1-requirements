# R-402 担保支付与迟到退回（REQ-014）

## 行为实例

| # | 场景 | 预期 |
|---|---|---|
| 1 | 窗口内支付成功 | 订单「待发货」，记 `paid_at` 与流水号，商品「待付款锁定」→「交易中」 |
| 2 | 同一 `txn_no` 回调三次 | 只有 1 条 `Payment`，订单状态不变（幂等） |
| 3 | 支付金额与应付不一致 | 400「支付金额与应付金额不一致，已转人工处理」 |
| 4 | 订单已超时取消后才支付成功 | 记一条 `result="迟到退回"` 流水 + 退款单，409「订单已关闭，迟到支付款项原路退回」，商品仍「已发布」 |
| 5 | 支付与取消并发 | 两者只有先提交的那一个生效，另一个按上面的口径处理 |
| 6 | 平台不沉淀资金 | 库里只有 `Payment` 流水与 `Settlement` 放款记录，没有「平台账户余额」字段 |

## 契约

- `trade/models.py::Payment(txn_no unique, kind ∈ {订单支付, 定金, 尾款}, result ∈ {成功, 迟到退回})`
- `trade/services.py::record_payment(*, kind, txn_no, amount, target: Order | Reservation, now=None, result=RESULT_OK) -> tuple[Payment, bool]`
  - `txn_no` 冲突时返回原流水，`created=False`（REQ-014「按支付流水号幂等」）
- `trade/services.py::pay(order, *, actor, txn_no, amount=None, now=None) -> Order`
- 迟到支付：`_record_late_payment(order, ...)` 写流水与退款单，**不恢复订单、不恢复商品**
- 「主动查单为准」在本期由调用方传入查询结果实现；接口不预置自动对账
