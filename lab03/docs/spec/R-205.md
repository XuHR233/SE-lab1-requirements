# R-205 检索与可见性（REQ-003、REQ-011、REQ-012）

## 行为实例

| # | 查询 | 预期 |
|---|---|---|
| 1 | 游客检索 | 只返回已发布与已预售 |
| 2 | 卖家检索 | 额外包含自己的草稿等未公开商品 |
| 3 | 管理员检索 | 任意状态都能看到 |
| 4 | 关键词"尼康 镜头" | 命中含"尼康"或"镜头"的商品（词间取或） |
| 5 | 关键词 + 分类 + 价格区间 | 三个条件取交 |
| 6 | 按价格升序 | 结果有序 |
| 7 | 价格下限 > 上限 | 报参数错误，不返回空列表混过去 |
| 8 | 页码越界 | 返回空列表，不报错 |
| 9 | 已售出商品 | 不出现在检索结果里 |

## 契约

- `catalog/search.py::visible_to(user) -> QuerySet[Product]`
- `catalog/search.py::search(*, user=None, keyword=None, category_id=None, tag=None, price_min=None, price_max=None, sort="newest", page=1) -> QuerySet`
- 排序白名单 `SORT_CHOICES`（newest / oldest / price_asc / price_desc），未知排序退回 newest
- 分页固定 `PAGE_SIZE = 12`，页码非法按第 1 页处理
- 关键词匹配范围：标题、品牌、描述、卖家用户名
