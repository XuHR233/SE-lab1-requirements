# R-405 收货确认、放款与自动确认（REQ-016 后半）

## 行为实例

| # | 场景 | 预期 |
|---|---|---|
| 1 | 买家确认收货 | 订单「已完成」，商品「交易中」→「已售出」，生成 `Settlement` 并记 `paid_out_at` |
| 2 | 重复确认收货 | 返回原订单，`Settlement` 仍 1 条（幂等，REQ-016） |
| 3 | 普通订单发货满 7 天未确认 | `sweep()` 自动确认并结算 |
| 4 | 预售订单：卖家确认到货后，从次日 00:00 起满 1 个完整日 | `auto_confirm_at = next_day_window_end(到货时间)`，到期自动确认 |
| 5 | 自动确认与买家手动确认并发 | 只有一次结算，`Settlement` 唯一约束兜底 |

## 契约

- `trade/services.py::confirm_receipt(order, *, actor, now=None) -> Order`
  - 幂等：已完成且有 `Settlement` → 直接返回
  - 成功后 `_sell(order)`（商品 → 已售出，已是已售出则直接返回）与 `_settle(order)`
- `trade/services.py::_auto_confirm_at(order, moment) -> datetime`
  - 有 `source_reservation` → `next_day_window_end(预约的 arrived_at or moment)`
  - 否则 → `moment + 7 天`
- `_settle(order)`：`Settlement.objects.get_or_create(order=order, ...)`，`paid_out_at` 在创建时写入
- `Settlement.order` 是 OneToOne，数据库层保证「同一订单只结算一次」
