# R-302 定金、卖家确认与到货（REQ-006 中段）

## 行为实例

| # | 场景 | 预期 |
|---|---|---|
| 1 | 15 分钟内支付定金，同一 `txn_no` 回调三次 | 状态「待确认」，`Payment` 只有 1 条（幂等） |
| 2 | 超过 15 分钟才付定金 | 预约已关闭，409「定金支付已超时（未收款不涉及退款）」 |
| 3 | 买家在「待付定金」阶段取消 | 已取消，退款 0 |
| 4 | 卖家在「待确认」阶段拒绝 | 已拒绝，定金全额退 |
| 5 | 卖家在「待确认」阶段确认 | 「待到货」，记录 `seller_confirmed_at` |
| 6 | 卖家确认到货 | 「待付尾款」，`final_due_at` = **次日 00:00 + 24h** |
| 7 | 23:00 确认到货 | 窗口为次日 00:00 至次日次日 00:00（不是「确认后 24h」） |
| 8 | 尾款窗口内未付尾款 | `sweep()` 关闭为「已取消」，定金不退 |
| 9 | 有效期届满仍未成交 | `sweep()` 关闭，定金全额退 |
| 10 | 他人替买家付定金 | 403 且写 denied 日志 |

## 契约

- `reservations/services.py::pay_deposit(reservation, *, actor, txn_no, now=None) -> Reservation`
  - 先按 `txn_no` 查 `Payment` 命中即幂等返回，再判状态（REQ-014 回调幂等）
- `seller_confirm` / `seller_reject` / `confirm_arrival` / `pay_final` / `cancel`
- `common/timebox.py::next_day_window_end(moment)` = 次日本地 00:00 + 24h
- `sweep(*, now=None) -> int`：定金超时、有效期届满、尾款逾期三类，可由
  `manage.py sweep_expired --now <ISO>` 驱动（cron 每分钟一次）
- 取消的退款口径集中在 `_cancel_terms()`：定金阶段买家取消不退；确认前取消全额退；
  确认后买家取消不退、卖家违约取消全额退。退款单写到 `trade.models.Refund(reservation=...)`
