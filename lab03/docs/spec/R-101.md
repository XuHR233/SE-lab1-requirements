# R-101 注册与登录（REQ-001）

## 行为实例

| # | 输入 | 预期 |
|---|---|---|
| 1 | 手机号 13900000001 + 正确验证码 + 合规密码 | 201，库里 1 条用户 |
| 2 | 已注册的 13800000001 再注册 | 400「该手机号已注册」，总数不变 |
| 3 | 手机号 `12345` / `1380000000a` / `23800000000` / 空 | 400，不落库 |
| 4 | 验证码 999999 | 400，不落库 |
| 5 | 正确手机号 + 正确密码登录 | 200，session 里有 uid |
| 6 | 密码错 vs 手机号不存在 | 两者返回同一句「手机号或密码不正确」 |

## 契约

- `POST /accounts/register`：`phone`(11 位)、`code`、`password`
- `POST /accounts/login`：`phone`、`password`
- 手机号唯一由数据库唯一约束保证，不是先查后插
- 密码走 Django PBKDF2，不自己写哈希
