# R-202 提交审核与驳回（REQ-004、REQ-005）

## 行为实例

| # | 操作 | 预期 |
|---|---|---|
| 1 | 没有图片就提交 | 拒绝，提示"至少上传一张图片" |
| 2 | 有图片提交 | 变待审核，开出一条待审流水 |
| 3 | 待审核期间再次提交 | 幂等，不新增第二条流水 |
| 4 | 审核通过（普通商品） | 变已发布 |
| 5 | 审核通过（勾了预售） | 变已预售，不是已发布 |
| 6 | 驳回但不写理由 | 拒绝，状态不变 |
| 7 | 驳回并写理由 | 变已驳回 |
| 8 | 驳回后改稿重提 | 流水累计两条，旧记录保留 |
| 9 | 审核自己发布的商品 | 拒绝（REQ-002 自审排除） |
| 10 | 商品已不在待审核时审核 | 拒绝，提示状态已变更 |

## 契约

- `catalog/services.py::submit_for_audit(product, *, actor) -> Product`
- `catalog/services.py::audit(product, *, auditor, approve, reason="") -> Product`
- 流水在提交时开、审核时补结论：`AuditRecord(product, submitted_version, created_at, auditor, approve, reason, audited_at)`
- 审核结论字段允许为空（`approve=None` 表示尚未审核），因此"提交了但没人审"是可查的状态
