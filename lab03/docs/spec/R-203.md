# R-203 内容修改与版本号校验（REQ-007）

## 行为实例

| # | 场景 | 预期 |
|---|---|---|
| 1 | 卖家在已发布商品上改价 | 变待审核，版本号 +1 |
| 2 | 审核通过后再看 | 回到已发布，版本号保持 |
| 3 | 两个编辑页都拿着 v1，先提交者成功 | 版本变 v2 |
| 4 | 后提交者仍提交 v1 | 拒绝，提示"商品已被修改，请刷新后重试"，内容不变 |
| 5 | 交易中的商品改内容 | 拒绝 |
| 6 | 没有可改字段 | 拒绝 |

## 契约

- `catalog/services.py::revise_content(product, *, actor, expected_version, **fields) -> Product`
- `expected_version != product.version` 抛 `VersionConflict`，且在写库之前判断
- 版本号在 `transit(..., bump_version=True)` 里用 `F("version") + 1` 自增，避免读改写丢失更新
- 内容字段白名单 `CONTENT_FIELDS = ("title", "description", "price", "category", "brand")`
