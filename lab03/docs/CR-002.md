# CR-002 · Day2–Day7 验收口径调整

确认日期：2026-11-25。适用范围：Atlas 原目录的课程内测版本。原工作卡与旧验收记录保留，冲突处以本记录为准。

| 编号 | 本轮口径与落点 |
|---|---|
| D2-01 / R-205 | 最近一次通过审核的时间是实际上架时间，用于列表排序与区间筛选；没找到通过记录时不伪造时间，排序放末尾。 |
| D2-02 / R-205 | 预约、下单时保存商品快照。历史单据、订单会话和历史图片按买家自己的快照展示，不因已结束的单据获得当前非公开详情权限。已公开商品仍可通过公开列表浏览。旧单只使用建立单据前可追溯的审核快照；缺资料不以当前商品覆盖。 |
| D3-01 / R-301～303 | 已付定金的预约到达有效期仍未确认到货：关闭预约、全额退回账面定金、商品转为已下架。到期任务与卖家的相关操作均执行同一规则。按时确认到货后，原尾款窗口与尾款逾期规则不变。 |
| D4-01 / R-403～404 | 仅在付款后未满 48 小时且未发货时，买家可自助全额退款；时限用已全额付款时刻（预售为尾款完成时刻）起算。纠纷裁定另走原工单。 |
| D4-02 / R-403 | 已付款满 15 天仍处于待发货时，自动全额退款并结束订单；到期后直接尝试发货也先结束订单，不依赖定时任务先运行。已进入纠纷的订单继续按原工单规则处理。 |
| D5-01～02 / R-501～502 | 网页不再提供消息隐藏操作，不改历史隐藏记录和已有 API；实时推送及消息表数据库级防改删不在本轮改动内。保留 CR-001，不增设独立「已和解」。 |
| D6-01 / R-602 | 按订单实际转为「已退款」的业务时刻，左闭右开统计一次；迟到款仍记退回流水，不改变订单退款时刻。旧已退款单的首次退款记录用于迁移；无退款证据的旧单不推定区间。 |
| D6-02 / R-601 | 自动好评不显示申诉入口，服务端也明确拒绝；管理员待办分页并保留超期提示。 |
| D6-03 / R-602 | 课程核心仍为 Lab1 的成交量、当前在架量和退款率；均分、好评率、响应时长标记未实现，原网页已有辅助成交图表不删。 |
| D7-01～02 / R-701～702 | 保留业务审计详情，补订单校验失败和关键状态变化；后台按订单、商品、操作人、动作、结果、时间组合筛选，展示中文逐行明细，空筛选要确认。不展示请求代码，普通账号只看本人订单时间线。未对所有历史模块逐项补写审计。 |
| D7-03 / R-703 | 课程版暂不追加恢复演练、附件备份或自动调度；原脚本不改。短信和支付仍为隔离内测。 |
