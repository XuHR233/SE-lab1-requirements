# CR-003 · 复购会话按订单显示

确认日期：2026-11-26。关联需求：REQ-016、REQ-018、REQ-019。

## 问题与决定

未发货订单裁定退款后，符合上架条件的原商品恢复已发布。原买家再次购买并付款时，虽然产生了新订单，沟通页仍使用会话早期绑定的订单和同会话内的旧工单，导致新单显示为「已退款」。

1. **从订单进入**：打开同一条会话，保留聊天记录；右侧显示入口对应的订单和该订单的商品快照，不以旧工单覆盖订单状态。
2. **从消息进入**：在同一商品、同一买家、同一卖家的订单中，优先显示进行中的订单；没有进行中的订单时，显示最近创建的一笔并标注「历史订单」（创建时间相同则按订单号取较新的一笔）；没有订单则显示「商品咨询」。
3. **工单按订单选择**：选中的订单没有工单时显示「暂无工单」，可按原规则为该订单请求客服介入；客服或管理员从工单进入时始终查看该工单的订单，接单、转交、交流和裁定权限不变。

本次不改变 Lab1/Lab2 的商品退款恢复规则、不生成新商品编号、不拆分会话、不变更数据库结构。旧的会话订单字段保留，但不再决定页面展示的订单。
